# Sistema Clínico

Sistema web para gestão de agendamentos de consultas e controle de pagamentos em clínicas médicas.

## 👥 Integrantes
- Geovanna Alves Rodrigues
- Luan Matos
- Lucas Kauan
- José Carlos
- Natanael Reis

## 🎯 Objetivo
Otimizar processos administrativos de clínicas, reduzindo erros de agendamento e facilitando o agendamento das consultas.

## ⚙️ Principais Funcionalidades
- Cadastro de pacientes
- Cadastro de médicos
- Agendamento e cancelamento de consultas

## 🛠️ Tecnologias
- Python + Django
- Bootstrap CSS

## 🗄️ Banco de Dados
Estrutura principal:
- clientes – cadastro de pacientes
- medicos - cadastro de médicos
- consultas - agendamento de consultas
